# Data Science Capstone Projects — Sadda Mounika

Capstone projects completed as part of the DataMites Certified Data Scientist program,
covering the full data science lifecycle — EDA, feature engineering, model building,
evaluation, and model comparison — across regression, classification, and deep learning
problems.

## Projects

| # | Project | Type | Best Model | Key Result |
|---|---|---|---|---|
| 1 | [Flight Fare Prediction](./) | Regression | Random Forest | R² = 0.817, MAE = ₹1,171 |

and key decisions.
